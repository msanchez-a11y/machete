    <li>Marzo</li>

    <li>Mayo</li>

  2. Febrero
  3. Marzo
  4. Abril
  5. Mayo
  6. Junio

<ul>
    <li>Julio</li>
    <li>Agosto</li>
    <li>Septiembre</li>
    <li>Octubre</li>
    <li>Noviembre</li>
    <li>Diciembre</li>

  • Abosto
  • Septiembre
  • Octubre
  • Noviembre
  • Diciembre

Cada elemento de la lista, lo encerramos entre <li> y </li>


Dos etiquetas que no tienen cierre

  • Saltos de linea forzados: <br> que viene de break.
  • Lineas de separacion: <hr> viene de horizontal ruler.

Comentarios

Los comentarios son fragmentos dentro del archivo donde colocamos notas que no van a ser mostrados en la página final.

Estos fragmentos deben estar encerrados entre estas 2 etiquetas especiales: "<--" y "-->"

Por ejemplo:

<--

Este es un bloque de comentarios
dentro de un archivo HTML.

-->

Tablas

<table>: Indica dónde comienza y termina nuestra tabla

<tr>: Representa una fila en la tabla

<th>: Representa una celda. Generalmente se usa para colocar los titulos en las columnas.

<td>: Representa una celda donde colocaremos información.

ATENCIÓN: Siempre tienen que agregar border="1" para que sean visibles los bordes de nuestra tabla.


<table border="1">
    <tr>
        <th>Nombre</th>
        <th>Curso</th>
    </tr>
    <tr>
        <td>Mauro</td>
        <td>2do A</td>
    </tr>
</table>
Nombre Curso
Mauro 2do A

Enlaces

Para agregar enlaces usaremos la etiqueta <a>, esta nos permitira agregar enlaces a paginas web y tambien a otras paginas que hayamos creado.

Tener en cuenta que dentro de <a> siempre tendremos que poner href=" " aqui es donde pondremos nuesto link para que los enlances funcionen.

ATENCIÓN: Si no ponemos ningún texto entre nuestras etiquetas <a> los enlaces jamas apareceran en nuestra página.


    <a href="Link o archivo.html">Ir a enlace</a>
